# ✨ MiniPop

[English](./README.md) | 简体中文

极简、原生的 macOS 划词即翻与搜索工具，单文件 Swift 编写，零第三方依赖。专为解决 PopClip 频繁模拟 `Cmd+C` **污染剪贴板历史**的痛点而生。

## 核心特性

- **绝不污染剪贴板**：纯 macOS 原生辅助功能接口（`AXUIElement`）读取选中文本，并针对 Chrome / Electron 应用自动开启 `AXManualAccessibility` 树，**全程不模拟 `Cmd+C`**，不占用 Paste / Raycast / Alfred 等剪贴板管理工具的空间。
- **划词即翻（零点击弹出）**：鼠标拖拽划词或双击选词松手后，自动在鼠标旁弹出悬浮窗并直接展示 Google 整段翻译结果。
- **中英自动互译 & `中/英` 一键切换**：检测到包含中文自动翻译为英文，其他语言自动翻译为简体中文；遇到中英混合文本时，直接点击浮窗右下角的 **`中/英`** 按钮即可在「译成中文 / 译成英文」之间即时切换。
- **点击卡片即复制**：直接点击翻译浮窗任意位置即可复制译文并自动收起；右下角提供 `🔍 搜原文` 一键调用默认浏览器进行 Google 搜索。
- **自动复用系统代理**：基于原生 `URLSession.shared`，自动继承 macOS 系统设置的 HTTP / HTTPS / SOCKS 代理，无需单独配置代理端口。
- **不抢焦点**：采用 `.nonactivatingPanel` 悬浮毛玻璃卡片，划词与阅读译文时不会打断当前应用焦点。
- **开机自启**：点击右上角状态栏 `✨` 图标即可随时开关「启用划词即翻」与「开机自动启动」。

## 环境要求

- macOS 13.0 及以上
- Xcode Command Line Tools（提供 `swiftc` 与 `iconutil`）

## 编译与运行

```bash
./build.sh
open MiniPop.app
```

也可以将编译好的应用移至「应用程序」目录：

```bash
cp -R MiniPop.app /Applications/
open /Applications/MiniPop.app
```

## 辅助功能权限配置

首次启动（或重新执行 `./build.sh` 编译签名后）需要授予「辅助功能」权限以读取选中文字：

1. 点击屏幕右上角菜单栏的 **`✨`** 图标。
2. 若第一行显示 `⚠️ 点击授权「辅助功能」权限…`，点击该项会自动打开 **系统设置 → 隐私与安全性 → 辅助功能**。
3. 开启 **MiniPop** 开关（如果是重新编译覆盖，请将开关先关再开一次，或删除后重新添加）。
4. 授权生效后，菜单栏第一行会变为 `✓ 辅助功能权限已开启`。

## 目录结构

- `main.swift` — 核心单文件源码（包含 AX 无剪贴板取词、Google 翻译请求、无焦点悬浮窗与状态栏菜单）。
- `make_icon.swift` — 原生绘制白底圆角 `✨` 应用图标并生成 `.icns`。
- `build.sh` — 一键打包 `MiniPop.app`、执行本地签名并运行内置自检测试。
